# Apiapiapi

Многофункциональный Telegram-бот на Aiogram.

## Цель проекта
Собрать набор полезных функций в одном Telegram-боте.

## Задачи
- Реализовать несколько команд
- Добавить обработчики сообщений
- Подключить внешние API

## Результат
Telegram-бот с набором полезных функций.

## Стек технологий
- Python, Aiogram 3

## Запуск
```bash
pip install aiogram
python main.py
```
