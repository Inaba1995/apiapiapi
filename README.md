# Телеграмм бот, "Мульти"


Telegramm бот на Python с возможностью подключать нейросеть и получать иные данные через API информационных сайтов. 

## Описание

Бот представляет собой мультипомошника для просмотра любых данных (возможность внесения доступна). 

**Основные функции:**
* "Погода у нас";
* "Финансовый вопрос";

## Требования

* Python 3.10 или выше;
* стандартная библиотека Python (включая `telebot`).
